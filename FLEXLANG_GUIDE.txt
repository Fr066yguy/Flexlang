# FlexLang Language Guide

Version: 1.0

FlexLang is a plugin-based programming language. The engine runs `.flx` files, while plugins add commands and features.

---

## 1. Basic Syntax

### Create a variable

```flexlang
create coins set 100
create player set "Alex"
create price set 12.5
```

### Display text

```flexlang
say "Hello, world!"
say "Welcome, {player}!"
say "You have {coins} coins."
```

Use `{variable}` inside text to display a variable's value.

### Comments

```flexlang
# This is a comment
create coins set 100
say "Comments explain your code."
```

Blank lines are also allowed.

---

## 2. Variables

Variables store information for later use.

```flexlang
create score set 0
create name set "Player"
create price set 9.99
```

Variable names can contain letters, numbers, and underscores. They cannot start with a number.

Valid:

```flexlang
score
player1
total_coins
```

Invalid:

```flexlang
1player
my score
```

## 3. Math Operators

The Math plugin supports arithmetic assignments.

| Operator | Meaning          | Example              |
| -------- | ---------------- | -------------------- |
| `+`      | Addition         | `score = score + 10` |
| `-`      | Subtraction      | `score = score - 5`  |
| `*`      | Multiplication   | `score = score * 2`  |
| `/`      | Division         | `score = score / 2`  |
| `//`     | Integer division | `score = score // 2` |
| `%`      | Remainder        | `score = score % 3`  |
| `**`     | Power            | `score = score ** 2` |
| `^`      | Power shortcut   | `score = score ^ 2`  |

Example:

```flexlang
create result set 1
result = result + 10
result = result * 5
result = result - 2
result = result / 2

say "Result: {result}"
```

Expected output:

```text
Result: 26.5
```

## 4. Comparison Operators

The Compare plugin checks whether values satisfy a condition.

| Operator | Meaning                  | Example                |
| -------- | ------------------------ | ---------------------- |
| `==`     | Equal to                 | `compare coins == 100` |
| `!=`     | Not equal to             | `compare coins != 0`   |
| `>`      | Greater than             | `compare coins > 50`   |
| `<`      | Less than                | `compare coins < 200`  |
| `>=`     | Greater than or equal to | `compare coins >= 100` |
| `<=`     | Less than or equal to    | `compare coins <= 100` |

Example:

```flexlang
create coins set 100

compare coins > 50
compare coins == 100
compare coins != 0

say "Comparison result: {comparison}"
```

The Compare plugin:

* Prints the comparison result.
* Stores the latest result in the `comparison` variable.
* Stores the result as `True` or `False`.

Note: Comparisons do not currently provide `if` statements by themselves.

---

## 5. Strings and Numbers

### Strings

```flexlang
create greeting set "Hello"
say "{greeting}, world!"
```

### Integers

```flexlang
create lives set 3
```

### Decimal numbers

```flexlang
create health set 99.5
```

Use quotes for text and leave numbers unquoted.

## 6. Current Plugins

Plugins are stored in the `features/` folder.

| Plugin  | File                  | Purpose             |
| ------- | --------------------- | ------------------- |
| Create  | `features/create.py`  | Creates variables   |
| Say     | `features/say.py`     | Displays text       |
| Math    | `features/math.py`    | Performs arithmetic |
| Compare | `features/compare.py` | Compares values     |

The engine loads Python plugin files from the `features/` folder when FlexLang starts.

To add a new feature, create another `.py` file in that folder and register its syntax with the `syntax()` decorator.

## 7. Project Structure

```text
Flexlang/
├── engine.py
├── hello.flx
├── FLEXLANG_GUIDE.txt
└── features/
    ├── create.py
    ├── say.py
    ├── math.py
    └── compare.py
```

* `engine.py` — Runs FlexLang programs and loads plugins.
* `hello.flx` — An example FlexLang program.
* `FLEXLANG_GUIDE.txt` — This reference guide.
* `features/` — Contains language extensions.

---

## 8. Running FlexLang

Open a terminal in the Flexlang folder and run:

```powershell
python engine.py hello.flx
```

FlexLang loads the plugins and executes the program.

---

## 9. Example Program

```flexlang
# A simple coin calculator

create player set "Alex"
create coins set 100
create bonus set 25

coins = coins + bonus

say "Player: {player}"
say "Coins after bonus: {coins}"

compare coins >= 100

say "Enough coins? {comparison}"
```

Expected output:

```text
Player: Alex
Coins after bonus: 125
125 >= 100 -> True
Enough coins? True
```

## 10. Planned Features

These are ideas for future plugins, not commands that are available yet.

* `if` / `else` — Conditional execution
* `repeat` — Loops
* `ask` — Get user input
* `function` — Create reusable functions
* `import` — Load other FlexLang files or libraries
* Lists and dictionaries
* File reading and writing
* Game development commands
* Custom error messages

**FlexLang design goal:** Add features through plugins whenever possible, keeping the core engine unchanged.
